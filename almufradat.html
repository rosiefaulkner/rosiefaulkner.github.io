UX, UI & Code Audit Changelog (v3.0)

6 Key Gotchas Identified & Fixed in This Build

1. Pure Arabic TTS Sanitizer + Arabizi Script Mapping + 0.75x Slow Toggle

Previously, entries containing Arabizi notes like (Ma7roog) or (Sa7eej) caused TTS engines to spell out Latin letters aloud. Every single entry now has a dedicated pure Arabic script target (ttsArabic) and passes through a strict Unicode Arabic regex (/[^\u0600-\u06FF\s]/g) before speaking. Added a 1.0x / 0.75x Slow toggle in the header.

2. Length-Balanced Quiz Distractor Algorithm

Randomly pairing a 12-word Jordanian proverb against three 1-word nouns made the correct choice obvious by length alone. Quiz Blitz now groups distractors by word-count & character-length buckets within the same category so options always look equally plausible.

3. Grid Match Tile Length Guard ("Overflow Fix")

Long conversational paragraphs broke the visual symmetry of 4×3 and 4×4 speed-matching tiles. Grid Match now automatically filters for concise words and idioms (≤ 36 Arabic chars), while full sentences and dialogues remain in Flashcards, Quiz Blitz, Cloze Builder, and Word Vault.

4. New Mode 4: Jordanian Idiom & Sentence Cloze Builder

Added an interactive fill-in-the-blank Cloze mode specifically designed to help you actively recall key words inside your Jordanian street idioms (e.g., غرقان لشوشتي بالشغل, علقانة بين حانا ومانا, اللي فات مات).

5. 3-Tier Spaced Repetition (New / Needs Review / Mastered)

Upgraded binary mastery into a 3-state SRS tracker. Any card you miss in Grid Match, Quiz Blitz, or Cloze Builder is automatically flagged as ⚠️ Needs Review so you can drill your weak spots with one click in the top bar.

6. Diacritic Line-Height Protection & Live Zoom (A- / A+)

Added vertical padding and line-height: 1.9 on all RTL Arabic containers so vowel marks (shadda, fatḥa, ḍamma) never clip, plus live A- / A+ font scaling in the header.
